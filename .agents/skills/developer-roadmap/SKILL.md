# Developer Roadmap Skill

Use this skill to access structured developer roadmaps, role-based skill prerequisites, and tech stack learning paths.

## Key Capabilities & Use Cases

- **Role Roadmaps**: Access standard skill paths for roles such as Frontend, Backend, DevOps, AI/Data Science, Security, Mobile, and Cloud Architecture.
- **Skill Progression**: Identify foundational, intermediate, and advanced topics for specific technologies.
- **Curriculum Planning**: Create customized learning paths and onboarding schedules for engineering teams or individual developers.

## Standard Workflow

1. **Identify Goal / Role**:
   - Determine the target role or technology stack (e.g., Node.js Backend, React Frontend, Kubernetes DevOps).
2. **Retrieve Roadmap Context**:
   - Query the `developer-roadmap` MCP server tools or docs for the target role/topic.
3. **Synthesize Progression Plan**:
   - Break down topics into:
     - **Prerequisites**: Fundamental CS concepts, language basics, version control.
     - **Core Knowledge**: Recommended frameworks, databases, API designs, and testing strategies.
     - **Advanced / Specialist**: Performance tuning, system architecture, security, scaling.
4. **Deliver Structured Guidance**:
   - Provide clear, actionable recommendations with learning milestones and practical project suggestions.

# Google Agents CLI Skill

Use this skill to build, configure, test, and manage AI agent applications using Google's `agents-cli` workspace and toolset.

## Key Capabilities & Use Cases

- **Agent Initialization**: Scaffolding new AI agent projects, tool configurations, and prompt manifests.
- **CLI Workflows**: Running local testing environments, debugging tool invocation traces, and managing environment parameters.
- **Packaging & Deployment**: Packaging skills, rules, and plugins into deployable agent configurations.

## Agents CLI Workflow

1. **Setup & Inspection**:
   - Verify environment setup and inspect active agent manifests.
2. **Developing Agent Capabilities**:
   - Define agent system instructions, tool definitions, and schema bounds.
3. **Local Testing & Simulation**:
   - Execute CLI test commands to validate agent performance against synthetic prompts.
4. **Build & Release**:
   - Bundle agent configuration assets for distribution or runtime execution.

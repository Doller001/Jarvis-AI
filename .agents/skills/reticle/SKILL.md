# Reticle Agent Evaluation Skill

Use this skill to evaluate, benchmark, and monitor AI agent performance, tool call accuracy, and execution traces.

## Key Capabilities & Use Cases

- **Agent Benchmarking**: Run standardized test scenarios against AI agent configurations.
- **Trace Analysis**: Inspect execution traces, tool call sequences, and reasoning steps for bottlenecks or failure points.
- **Metrics Generation**: Compute success rates, task completion latency, token efficiency, and safety compliance scores.

## Evaluation Workflow

1. **Benchmark Definition**:
   - Specify target tasks, expected outputs, and acceptable tool call patterns.
2. **Execution & Tracing**:
   - Run the agent on evaluation scenarios while recording full trace logs.
3. **Scoring & Reporting**:
   - Calculate precision, recall, task completion time, and context window efficiency.
   - Highlight failed steps, hallucinated tool calls, or invalid parameters for remediation.
